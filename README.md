# Licensing

Each Professional license includes support for **2 computers**.

### Online Activation

Paste your license key inside:

```
Settings
→ License
```

The software activates automatically.

---

### Offline Activation

Need an offline activation?

Generate your machine code and activate your license through:

```
abyzor.space/activate-offline
```

---

### Device Limit

Each license supports **2 devices**.

Deactivate an existing machine before moving your license to another computer.
